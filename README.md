# Meme Generator

Meme Generator is a React-based application that generates random meme images and allows users to add their own text to create customized memes.

The project was created to practice API integration, React state management, form handling, and dynamic UI updates.

## Features

* Generate random meme images
* Add custom text to memes
* Update meme content dynamically
* Interactive form controls
* Responsive interface
* React-based component structure

## Tech Stack

* React.js
* JavaScript
* Vite
* CSS

## What I Practiced

* Working with external APIs
* Managing React state
* Handling form inputs
* Updating UI dynamically
* Handling user interactions
* Building reusable React components

## Getting Started

### 1. Clone the repository

```bash
git clone https://github.com/Aryankarmur/Meme_generator.git
```

### 2. Navigate to the project

```bash
cd Meme_generator
```

### 3. Install dependencies

```bash
npm install
```

### 4. Start the development server

```bash
npm run dev
```

The application will be available on the local development server provided by Vite.

## Project Purpose

This project was created to practice React fundamentals, API integration, state management, and dynamic user interactions through a small practical application.
